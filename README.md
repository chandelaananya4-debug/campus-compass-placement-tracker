# Campus Compass — Placement Tracker

A student placement tracker built with Python, Streamlit, Pandas, NumPy, and CSV file concepts.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
1. Create a GitHub repository.
2. Upload `app.py`, `requirements.txt`, and this README.
3. Visit https://share.streamlit.io and sign in with GitHub.
4. Choose **Create app**, select your repo, branch `main`, and entry file `app.py`.
5. Click **Deploy** and share the generated `*.streamlit.app` URL.

## Important
- The starter uses fictional demo records.
- This beginner deployment keeps edits in app session memory. Export a CSV backup; changes can reset when the app restarts.
- Do not use identifiable or confidential student records without permission.
- For persistent shared editing, use a database and authentication.
